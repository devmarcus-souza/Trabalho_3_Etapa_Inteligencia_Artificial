#include <stdio.h>

// Função para imprimir um array
void imprimirArray(int arr[], int tamanho) {
    int i;
    for (i = 0; i < tamanho; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// Função para implementar o Bubble Sort
void bubbleSort(int arr[], int tamanho) {
    int i, j, temp;
    // O loop externo percorre todo o array
    for (i = 0; i < tamanho-1; i++) {
        // O loop interno compara adjacentes e troca se necessário
        for (j = 0; j < tamanho-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                // Troca arr[j] e arr[j+1]
                temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }
}

// Função principal para testar o Bubble Sort
int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int tamanho = sizeof(arr)/sizeof(arr[0]);
    printf("Array original: \n");
    imprimirArray(arr, tamanho);
    bubbleSort(arr, tamanho);
    printf("Array ordenado: \n");
    imprimirArray(arr, tamanho);
    return 0;
}

### Como Funciona o Bubble Sort:
- O Bubble Sort é um algoritmo de ordenação simples que funciona comparando pares de elementos adjacentes e trocando-os se estiverem na ordem errada.
- Este processo é repetido várias vezes até que o array esteja completamente ordenado.
- O nome "Bubble Sort" vem do fato de que, como as maiores "bolhas" (maiores valores) "subem" para o topo do array em cada passo, enquanto as menores "bolhas" "descem" para o fundo.

### Complexidade do Bubble Sort:
- **Melhor Caso**: O(n) (quando o array já está ordenado)
- **Pior Caso**: O(n^2)
- **Caso Médio**: O(n^2)

O Bubble Sort é eficiente para pequenos conjuntos de dados ou para conjuntos de dados já parcialmente ordenados. No entanto, para conjuntos maiores, ele é geralmente menos eficiente em comparação com algoritmos de ordenação mais avançados como Quick Sort, Merge Sort ou Heap Sort.
